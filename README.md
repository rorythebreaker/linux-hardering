# Linux Hardering

Bash-based Debian/Ubuntu server hardening toolkit.

## Development

The `development` branch is for v2.2 and later changes, including support for multiple SSH public keys in `authorized_keys`.

**Status:** Script upload is pending. This README does not indicate that the tool is deployed or tested.

## Safety

Test on a disposable VM and keep console access before applying SSH or firewall changes. A syntax check is not a substitute for integration testing.
